# Canto

Research-stage project exploring a development workspace that connects existing
editors, coding agents and source control. Scope, architecture and stack are
not settled.

- Get concrete implementation scope from the user before rebuilding.
- Previous Go and Rust implementations are historical experiments, not current
  baselines. Do not resume them or treat older handoffs as settled direction.
- Keep private research out of this public repository.
- Preserve the Apache-2.0 license and Git history. Do not modify Ion or AVC.

There is currently no application code, build system or test suite.
